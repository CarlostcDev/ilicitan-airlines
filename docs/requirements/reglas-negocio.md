# Reglas de negocio

Las reglas de negocio definen las condiciones y restricciones que deberán cumplirse durante el funcionamiento de Ilicitan Airlines, independientemente de la interfaz utilizada.

| ID        | Regla                                                                                                                                                                                                                                                                               |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **RN-01** | Cada dirección de correo electrónico podrá estar asociada a una única cuenta de usuario.                                                                                                                                                                                            |
| **RN-02** | Una cuenta creada mediante el registro con correo electrónico y contraseña no podrá vincularse posteriormente como una cuenta de Google independiente, y una cuenta creada mediante Google no podrá registrarse posteriormente mediante correo electrónico como una segunda cuenta. |
| **RN-03** | Un usuario podrá realizar múltiples reservas, siempre que cada una cumpla las condiciones establecidas por el sistema.                                                                                                                                                              |
| **RN-04** | No se podrá realizar una reserva para un vuelo cuya fecha de salida ya haya pasado.                                                                                                                                                                                                 |
| **RN-05** | Un usuario únicamente podrá consultar y gestionar las reservas asociadas a su propia cuenta.                                                                                                                                                                                        |
| **RN-06** | Una reserva podrá incluir como máximo 8 pasajeros.                                                                                                                                                                                                                                  |
| **RN-07** | La clase de viaje seleccionada para una reserva se aplicará a todos los pasajeros incluidos en dicha reserva.                                                                                                                                                                       |
| **RN-08** | Los usuarios registrados mediante el formulario de registro recibirán una fotografía de perfil predeterminada si no proporcionan una propia.                                                                                                                                        |
| **RN-09** | Los usuarios registrados mediante Google utilizarán como fotografía de perfil la proporcionada por su cuenta de Google, cuando esté disponible.                                                                                                                                     |
| **RN-10** | Un vuelo deberá tener un aeropuerto de origen y un aeropuerto de destino diferentes.                                                                                                                                                                                                |
| **RN-11** | Los administradores no accederán a la interfaz destinada a los usuarios normales, sino únicamente al panel de administración correspondiente a su rol.                                                                                                                              |
| **RN-12** | Los administradores podrán importar y exportar información del sistema mediante archivos en formato CSV.                                                                                                                                                                            |
| **RN-13** | Un asiento no podrá estar asignado simultáneamente a más de un pasajero en un mismo vuelo.                                                                                                                                                                                          |
| **RN-14** | Un vuelo no podrá vender más plazas que la capacidad disponible de la aeronave asignada.                                                                                                                                                                                            |
| **RN-15** | La asignación de una aeronave a un vuelo deberá ser compatible con las características y condiciones establecidas para dicho recorrido.                                                                                                                                             |
| **RN-16** | Los datos de una reserva confirmada deberán conservarse independientemente de que el usuario cierre sesión o deje de utilizar temporalmente la aplicación.                                                                                                                          |
| **RN-17** | Las operaciones administrativas estarán limitadas a las funciones autorizadas para el rol correspondiente.                                                                                                                                                                          |
| **RN-18** | La disponibilidad de un asiento deberá actualizarse cuando este sea asignado a una reserva confirmada, evitando que pueda ser seleccionado posteriormente por otro usuario.                                                                                                         |
| **RN-19** | Una reserva de ida y vuelta deberá estar formada por un vuelo de ida y un vuelo de regreso compatibles con las fechas seleccionadas.                                                                                                                                                |
| **RN-20** | Las condiciones de modificación y cancelación de una reserva deberán respetar las condiciones establecidas para el billete adquirido.                                                                                                                                               |
| **RN-21** | La disponibilidad del check-in estará condicionada por las reglas establecidas para el billete, el vuelo y el periodo habilitado para realizarlo.                                                                                                                                   |
| **RN-22** | Los datos de un usuario no podrán ser modificados ni eliminados por otro usuario que no disponga de los permisos administrativos correspondientes.                                                                                                                                  |
